# Review tab parity

What the Review tab and the Tools menu's proofing and protection items do in Documents, compared
with the leading desktop word processors. Everything listed as implemented saves to DOCX and
reopens, and goes through the editor's transactions (undo, read-only rules, protection).

## Implemented

**Proofing**
- Editor pane (ribbon *Editor*): spelling issues grouped by word with Change, Change All, Ignore,
  Ignore All and Add to Dictionary; a *Check One by One* walkthrough (F7, the existing Spelling
  pane). Grammar and refinements from Puter AI (grammar, punctuation, clarity, conciseness,
  formality, inclusive language): off until turned on, marked *AI*, nothing sent until *Check with
  AI*; suggestions drawn as blue double underlines, Accept/Ignore. Statistics and readability
  computed locally: words, characters, paragraphs, sentences, averages, Flesch Reading Ease (with a
  plain-language band), Flesch–Kincaid grade, passive sentences (pattern estimate). Selection-aware.
- Thesaurus pane (Option+Cmd+R on a Mac, Shift+F7 everywhere): senses by part of speech with
  definitions, synonyms and antonyms; Insert (keeps the word's capitalization), Copy, Look Up, Back.
  Data: WordNet 3.1, generated by `tools/generate-thesaurus.mjs` into `public/thesaurus/en.json`
  (2.9 MB, about 0.9 MB compressed), fetched on first use; license and provenance in
  `public/thesaurus/` and checked by `npm run check:licenses`. Context menu *Synonyms* submenu.
- Word Count (Cmd/Ctrl+Shift+G, status bar, Tools): pages, words, characters with and without
  spaces, paragraphs, lines; selection-aware; *Include text boxes, footnotes and endnotes* toggle.
- Spelling menu: Hide Spelling Errors / Hide Grammar Errors in This Document (saved), Reset Ignored
  Words, Recheck, Check Spelling as You Type.

**Accessibility**
- Check Accessibility pane: missing alternative text, tables without a header row, low text
  contrast (WCAG 2.1 ratios), hard-to-read highlight colors, skipped heading levels, merged cells,
  blank table rows, empty paragraphs used for spacing, repeated spaces/tabs, unclear link text.
  Grouped by severity with explanations, Go To, and quick fixes (add a description, use first row
  as header, automatic color, remove highlight, remove empty paragraphs, single space, delete row).
  *Keep checking while I work*. Status-bar hook: `w.accessibilitySummary()` returns
  `{ errors, warnings, tips, label, open }`.

**Language**
- Translate selection (pane with Insert, which marks the text's language, and Copy) and Translate
  Document (a new document) through Puter AI; Set Document Translation Language.
- Language dialog: proofing language for the selection (`w:lang`), *Do not check spelling or
  grammar* (`w:noProof`), *Detect language automatically*, *Set As Default* (docDefaults).
  `w.proofingLanguage()` for the status bar.

**Comments**
- New (Cmd+Option+A / Ctrl+Alt+M), Delete (this, all resolved, all shown, all), Previous/Next,
  Resolve/Reopen, Reply, Edit (existing), Show Comments contextual (cards) or as a List (Comments
  pane with search, resolved toggle and a people filter that includes mentions). @mentions: typing
  `@` suggests reviewers (comment and revision authors and you); mentions are highlighted.

**Tracking**
- Track Changes split: For Everyone (saved setting), Just Mine (this session only, the file keeps its
  setting), Off; Lock Tracking with an optional password (protection `trackedChanges`).
- Display for Review (Simple, All, No Markup, Original). Show Markup: Comments, Ink (when the draw
  tools provide it), Insertions and Deletions, Formatting, Balloons (revisions in balloons / all
  inline / only comments and formatting), Specific People.
- Reviewing Pane vertical or horizontal, with move and formatting descriptions ("Formatted: Bold").
- Tracking Options dialog with live preview: insertion/deletion marks and colors, change bar
  position (left, right, outside, none) and color, moves (track, marks, color), formatting (track,
  mark, color), balloons, pane orientation, per-reviewer colors.
- Formatting and paragraph-property changes are tracked (`rPrChange`/`pPrChange`) and can be
  rejected; cut-and-paste becomes a move.

**Changes**
- Accept/Reject: and move to next, this change, all changes shown (respects Show Markup), all, all
  and stop tracking; Previous/Next change; balloons have accept/reject buttons.

**Compare**
- Compare Documents: original and revised from this document, the device or Puter; label for
  changes (defaults to the revised file's last author); word or character level; formatting, case,
  white space and table options. The result shows the original, compared and revised text side by
  side with synchronized scrolling, then opens as a new document or downloads.
- Combine Documents: keeps the original with its own changes and comments and adds the revised
  copy's differences as tracked changes (its own tracked insertions keep their authors).

**Protect**
- Restrict Editing pane: formatting restrictions (choose allowed styles; others are written as
  locked), editing restrictions (read only, tracked changes, comments, filling in forms),
  exceptions per region for everyone or named people (*More users…*), region list with Go To and
  Remove, Start Enforcing Protection with an optional password (hashed per the specification),
  Your permissions view with Find Next Region I Can Edit, Show All Regions, highlighting, and Stop
  Protection (asks for the password).
- Always Open Read-Only (File menu): saved as a recommendation; opening such a document offers a
  read-only session with *Edit Anyway*.

**Ink**
- Hide Ink appears only when the drawing tools provide `toggleInk`.

**Menus**: `extendMenu('tools')` (Spelling and Grammar, Thesaurus, Translate, Language, Word Count,
Check Accessibility, Track Changes ▸ Lock Tracking / Tracking Options / Compare, Combine, Protect
Document), `('view')` (Markup, Reviewing Pane, Comments Pane), `('insert')` (Comment), `('file')`
(Always Open Read-Only, Protect Document; also in the File backstage). `contextMenuItems('text')`:
Synonyms, Translate, New Comment, accept/reject and comment actions.

## Approximations

- Grammar and style checking needs Puter AI (no local grammar engine); spelling is English only.
- Passive voice and syllables are estimates from patterns; readability formulas are the standard
  English ones.
- Thesaurus coverage is WordNet's: some common senses are missing (single-word synsets are dropped
  to keep the file small) and adjective lists can be loose.
- *Just Mine* tracking is per session, not per author identity across devices.
- Protection is enforced by this editor; it does not encrypt anything. Forms protection treats
  content controls as the fields.
- Compare pairs paragraphs by similarity and table rows by content; rows only in the original
  follow the table as deleted paragraphs; pictures and fields from the other document are not
  copied; moves are not detected.
- Balloons share the comment column; very dense pages may stack them below their anchors.

## Gaps

- Table cell revision highlighting (inserted/deleted/merged cells) and table row/cell revisions.
- Revisions in headers, footers, notes and text boxes (those documents stay read-only).
- Notifications for @mentions, modern threaded "people" identities.
- Style gallery filtering under formatting restrictions (the guard refuses locked styles instead).
- Ink annotations themselves (owned by the drawing tools).
- Interoperability of protection passwords was verified against an independent implementation of
  the specification, not against a desktop application.
