# Desktop word-processor parity roadmap

Documents aims to offer the full capability set of a professional desktop word processor, with
cleaner dialogs and better keyboard flow where the conventional design is clumsy. This file tracks
the work by area; each area keeps a detailed record in `docs/parity/<area>.md` (what is
implemented, what is approximated, remaining gaps) and its OOXML notes in `docs/conformance.md`.

| Area | Scope | Status |
| --- | --- | --- |
| Application chrome | Menu bar, File backstage, title bar (quick access, AutoSave, editing modes, command search), status bar, ribbon collapse and KeyTips, document context menus, keyboard shortcuts and customization | In progress |
| Home and Format | Font, Paragraph, Tabs, Borders and Shading, Bullets and Numbering, Change Case and Style dialogs; Styles pane, Style Inspector, Reveal Formatting; Select menu; paste options and Paste Special; advanced Find and Replace; Format Painter; text effects; dictation | In progress |
| Insert | Pages, pictures, shapes, icons, diagrams, charts, screenshots, header/footer and page-number galleries, text boxes, Quick Parts and fields, WordArt, drop caps, signature lines, date and time, text from file, equations, symbols | In progress |
| Tables | Table grid and dialog, draw and convert, quick tables, Table Design and Table Layout tools, Table menu, mouse resizing, formulas, sorting | In progress |
| Design and Layout | Themes, style sets, colors, fonts, effects, watermarks, page color and borders; page setup, columns, breaks, line numbers, hyphenation | In progress |
| References | Tables of contents, footnotes and endnotes, citations and bibliography, captions and tables of figures, index, table of authorities, smart lookup | In progress |
| Mailings | Envelopes, labels, mail merge (recipients, fields, rules, preview, merge to document/print/email) | In progress |
| Review | Editor pane, thesaurus, word count, accessibility checker, translation and language, comments, tracking options, compare and combine, restrict editing | In progress |
| View modes | Read mode, web layout, outline, draft, side-to-side page movement, split window, thumbnails | Planned |
| Pictures and shapes | Picture and Shape Format tools, arrange (position, align, group, rotate, selection pane), direct manipulation | Planned |
| Draw | Pens, highlighter, eraser, lasso, ink to shape | Planned |
| Collaboration and assistant | Sharing, co-editing, writing assistant pane | Planned |
