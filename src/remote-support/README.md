# Remote Support

Consent-based remote assistance UI inspired by TeamViewer/AnyDesk.

| Capability | TeamViewer / AnyDesk (DOCUMENTED) | This app |
| --- | --- | --- |
| Consent before view | Yes | Yes (required) |
| Separate control opt-in | Yes | Yes |
| Connection list + audit log | Yes | Yes |
| LIVE cross-network remote | Yes | No — mock local loopback only |
| Unauthorized / silent access | N/A (product TOS) | Never — not provided |
