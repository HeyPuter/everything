Office Hub

One place to launch Everything’s office apps — Documents, Spreadsheet, Presentation, and PDF — and route files by extension. Install this page as an app on Android (Chrome → Install app / Add to Home screen).

About / #31

Addresses #31 (WPS-like office on Android) via an installable web hub over the existing suite. A single >500 MB native Android APK bundling Collabora/LibreOffice engines is out of scope for this monorepo’s Vite apps (blocked on packaging model); format depth lives in each linked app.
