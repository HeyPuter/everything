FreeCell

How to play
  • Build foundations up by suit from Ace to King.
  • Build cascades down by alternating colours. Empty cascades accept any card.
  • Each free cell holds one card. Longer runs use freecells and empty columns (supermove).
  • Select a card, then a destination. Select the same pile again to auto-place when legal.
  • Deal numbers match the classic Microsoft FreeCell RNG (DOCUMENTED public algorithm).
