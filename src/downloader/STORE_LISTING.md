# Downloader

**Fast, organized download manager for your Puter Cloud**

## Short description

Download files directly into your Puter Cloud account with real-time transfer speeds, pause/resume support, automatic categorization, and local device export. Alternative to Internet Download Manager (IDM).

## Long description

Downloader gives Puter users a dedicated download workstation. Whether saving videos, audio tracks, archives, software packages, or documents from the web, Downloader streams them cleanly into your cloud environment.

Files are placed directly into `/Downloads/` in your Puter filesystem, making them instantly available to the Puter Files app, code editor, media player, or any connected cloud tool. Need a file on your local machine instead? Export completed items to your local computer in one click.

With live bandwidth monitoring, estimated time of arrival (ETA), category filtering, URL probing, and seamless persistence via Puter KV, Downloader brings desktop-grade download acceleration and organization to the cloud.

## Key features

- Direct Puter Cloud downloads saved to `/Downloads/`.
- Local device download fallback option.
- Real-time bandwidth indicator with instantaneous transfer speed (KB/s, MB/s) and ETA.
- Automatic file categorization (Videos, Audio, Documents, Archives, Programs, Images).
- URL probing to detect remote file size and filename before downloading.
- Pause, resume, retry, and clear controls.
- 1-click test downloads for instant out-of-the-box verification.
- Cloud state synchronization across sessions using Puter KV.
- Responsive modern dark and light modes.

## Who it's for

- Anyone downloading web resources, archives, and media directly into Puter.
- Users looking for a lightweight, ad-free alternative to IDM and FDM on cloud operating systems.
- Developers needing to pull remote artifacts or assets straight into Puter storage.
