| Capability | Adobe InDesign (DOCUMENTED) | This app |
| --- | --- | --- |
| Master pages + text frames | Yes | Yes |
| Multi-column frames | Yes | Yes |
| LIVE Creative Cloud / print RIP | Yes | No |
| Offline PDF export | Yes | Yes (toy PDF 1.4) |
