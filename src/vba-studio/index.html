        About this VBA subset
        

          This is an original VBA-inspired interpreter answering
          #25 — not Microsoft Visual Basic
          for Applications, and not a redistributed Office binary. Supported today: Sub,
          Dim, For/Next, If/Then/Else, MsgBox,
          Range("A1").Value, arithmetic, and & concatenation.
