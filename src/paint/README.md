# Paint

Classic bitmap drawing inspired by MS Paint — original browser implementation.

| Capability | MS Paint (DOCUMENTED) | This app |
| --- | --- | --- |
| Pencil / brush / eraser | Yes | Yes |
| Line, rectangle, ellipse | Yes | Yes |
| Flood fill | Yes | Yes |
| Undo + PNG export | Yes | Yes |
| Layers / selection transforms | Yes (modern) | No (v0) |
| Runs fully offline in-browser | Desktop app | Yes |
