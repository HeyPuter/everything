# Photo Library

Lightroom-inspired catalog workflow (ratings, flags, non-destructive adjust). Not a Photo Studio clone.

| Capability | Adobe Lightroom (DOCUMENTED) | This app |
| --- | --- | --- |
| Catalog / ratings / flags | Yes | Yes |
| Non-destructive adjust | Yes | Yes (CSS preview filters) |
| LIVE Creative Cloud sync / RAW | Yes | No |
| Pixel editor (Photoshop-style) | Develop module | No — use Photo Studio |
