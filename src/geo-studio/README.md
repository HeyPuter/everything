# Geo Studio

Local map layers / markers / GeoJSON for ArcGIS-style GIS workflows.

| Capability | ArcGIS (DOCUMENTED) | This app |
| --- | --- | --- |
| LIVE basemap / feature services | Yes | No |
| Offline layers + markers | Yes | Yes |
| GeoJSON export | Yes | Yes |
| Runs fully in-browser | Often desktop/cloud | Yes |
